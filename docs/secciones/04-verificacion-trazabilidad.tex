\section{Verificación y trazabilidad de requisitos}

\subsection{I. Métodos de verificación}

\begin{itemize}
    \item \textbf{Prueba:} Ejecutar el software bajo condiciones definidas y comparar
    los resultados obtenidos con los esperados.
    \item \textbf{Inspección:} Examinar directamente interfaces, documentos o
    componentes para comprobar el cumplimiento de un requisito.
    \item \textbf{Análisis:} Evaluar propiedades del software mediante cálculos,
    revisiones técnicas o análisis de resultados.
    \item \textbf{Demostración:} Ejecutar una funcionalidad y observar su
    comportamiento para evidenciar que cumple un requisito.
\end{itemize}
